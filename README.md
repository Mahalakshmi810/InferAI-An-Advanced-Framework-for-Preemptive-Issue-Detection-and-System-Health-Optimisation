INFERAI-Infrastructure AI is an advanced framework for pre-emptive issue detection and system health optimisation.In a nutshell, A smart network monitoring system built for enterprises.

Usage includes:
1.INSTALLATION OF PACKAGES
Install the necessary packages from requirements.txt

2.EXECUTION OF THE PYTHON FILE
streamlit run main.py in the terminal

3. HUGGING FACE SPACES DEPLOYMENT
- Create a new Space on Hugging Face and choose the Gradio SDK.
- Push this repository to the Space or upload the files.
- Ensure `app.py` is present at the repository root.
- Hugging Face will install dependencies from `requirements.txt` and launch the app automatically.

> The original Streamlit app is preserved in `old_App_streamlit.py` if you want to reuse it later.
